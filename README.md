# ОНИКС Детейлинг.рф — сайт студии

Адаптивный сайт для студии детейлинга с формой записи, приёмом отзывов, галереей, контактами и защищённой админ-панелью.

## Важно перед публикацией

- Визуальный стиль вдохновлён современными премиальными сайтами детейлинга и ссылкой на Behance из задания. Страница Behance не отдала исходные изображения для точного копирования, поэтому это самостоятельная реализация, а не пиксельная копия.
- Изображения в галерее и блоках — внешние Unsplash-референсы, не подтверждённые фотографии студии. Замените их на разрешённые реальные фото из галереи бизнеса до запуска.
- Оценка, количество оценок, адрес, телефон и часы работы взяты из публичной карточки и требуют подтверждения владельцем.
- Официальный прайс не подтверждён. На сайте намеренно нет выдуманных цен.
- Запись сохраняется на сервере в `data/submissions.json`; отзыв сохраняется со статусом `pending` и требует модерации. Автоматической записи в календарь/CRM и автоматических SMS/Telegram-уведомлений нет.

## Требования

- Node.js 18 или новее
- npm

## Запуск в Windows

1. Распакуйте архив.
2. Убедитесь, что установлен Node.js 18 или новее.
3. Откройте папку проекта в терминале. Устанавливать npm-пакеты не требуется — сервер использует встроенные модули Node.js.
4. Создайте `.env` на основе `.env.example` и задайте уникальный `ADMIN_TOKEN`. В PowerShell можно сделать копию так:

   ```powershell
   Copy-Item .env.example .env
   ```

   Node.js 20.6+ умеет загружать `.env` через `--env-file`:

   ```powershell
   node --env-file=.env server.js
   ```

5. Откройте `http://localhost:3000`.
6. Админ-панель: `http://localhost:3000/admin.html`, вход — значение `ADMIN_TOKEN`.

Для запуска с переменными окружения в PowerShell:

```powershell
$env:ADMIN_TOKEN="replace-with-a-long-random-secret"
npm start
```

## Функции

- Адаптивная навигация и мобильная кнопка записи.
- Форма записи: имя, телефон, услуга, автомобиль, дата, время и комментарий.
- Серверная валидация, honeypot-поле и простой rate limit для API.
- Отзывы с оценкой 1–5 и статусом модерации.
- Админ-панель: просмотр заявок, изменение статусов, одобрение/отклонение отзывов.
- Галерея с увеличением, перелистыванием стрелками и закрытием по клику снаружи.
- Ссылки звонка, карты и внешних отзывов.

## Размещение на хостинге

Разместите как Node.js Web Service, укажите команду запуска `npm start`, задайте `ADMIN_TOKEN` и `NODE_ENV=production`. Убедитесь, что хостинг предоставляет постоянный диск: файл `data/submissions.json` иначе может очищаться при перезапуске/деплое. Для production с несколькими инстансами замените файловое хранилище на PostgreSQL и добавьте резервное копирование, политику хранения персональных данных и защиту формы от злоупотреблений.

## Данные и приватность

Форма обрабатывает имя, телефон, выбранную услугу и комментарий. Перед публичным запуском добавьте полноценную политику конфиденциальности, юридически корректное согласие на обработку персональных данных и проверьте требования применимого законодательства. Не публикуйте отзывы, пока они не одобрены владельцем.

## Telegram-уведомления о новых заявках

Интеграция отправляет владельцу студии сообщение при создании заявки. В сообщении есть имя и телефон клиента, услуга, автомобиль, дата/время и комментарий. Встроенные кнопки позволяют отметить заявку как подтверждённую, отклонённую или как ту, по которой уже связались с клиентом; статус обновляется в той же базе, что и в админ-панели. Заявка сохраняется на сервере **до** отправки уведомления, поэтому временная ошибка Telegram не приводит к потере заказа.

### 1. Создайте бота

1. Откройте официальный аккаунт [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`, укажите имя (например, `ОНИКС Детейлинг заявки`) и username, который заканчивается на `bot`.
3. BotFather выдаст токен. Скопируйте его и никому не отправляйте — это пароль управления ботом.
4. Откройте чат с созданным ботом и нажмите **Start** или отправьте `/start`.

### 2. Настройте сервер

1. Скопируйте `.env.example` в `.env`.
2. Заполните `TELEGRAM_BOT_TOKEN` токеном, выданным BotFather.
3. Запустите сайт командой `npm start`, затем откройте чат с ботом и отправьте `/start`. Бот ответит вашим Telegram Chat ID.
4. Скопируйте ID в `TELEGRAM_ADMIN_CHAT_ID` в `.env`.
5. Перезапустите сервер. После повторного `/start` бот должен подтвердить, что подключён.

Пример `.env` (значения ниже вымышленные):

```dotenv
PORT=3000
ADMIN_TOKEN=replace-with-a-long-random-secret
BUSINESS_PHONE=79251009090
TELEGRAM_BOT_TOKEN=123456789:replace_this_with_the_real_bot_token
TELEGRAM_ADMIN_CHAT_ID=123456789
```

Не добавляйте `.env` в Git и не размещайте токен в HTML/JavaScript. `.env` уже добавлен в `.gitignore`. Если ранее опубликовали токен, отзовите его через BotFather и выпустите новый.

### 3. Проверьте интеграцию

1. Убедитесь, что сервер запущен и владелец нажал Start в боте.
2. Отправьте тестовую заявку через форму сайта.
3. Заявка должна появиться в админ-панели и прийти владельцу в Telegram.
4. Нажмите одну из кнопок в Telegram и проверьте изменение статуса в админ-панели.

Бот использует long polling и Telegram Bot API, внешние npm-зависимости не нужны. Если токен не задан, сайт работает как раньше, а уведомления отключены. Если у бота ранее настраивали webhook или другой процесс уже вызывает `getUpdates`, удалите webhook/остановите второй poller перед запуском этой интеграции. Не запускайте две копии сайта с одним токеном одновременно: Telegram допускает только одного активного long-polling-потребителя.

### Примечания для production

- Переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_ID` нужно задать и в настройках хостинга, если `.env` не загружается на хостинге.
- Используйте постоянное хранилище для `data/submissions.json`.
- Уведомления содержат персональные данные клиентов; ограничьте доступ к чату владельцем и соблюдайте применимые требования по обработке персональных данных.
